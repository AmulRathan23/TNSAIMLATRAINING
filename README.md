 TNSAIML_Training
 Credit Card Fraud Detection Using Classification Techniques
This project analyzes credit card transaction data and identifies fraudulent transactions using Machine Learning classification algorithms. It predicts whether a transaction is legitimate or fraudulent and helps identify suspicious financial activities.

Technologies Used:
- Python
- Pandas
- NumPy
- Scikit-learn
- Imbalanced-learn (SMOTE)
- XGBoost
- Streamlit
- Matplotlib
- Seaborn
- Joblib

 Features:
- ULB Credit Card Fraud Detection dataset analysis
- Data preprocessing and feature selection
- Handling imbalanced data using SMOTE
- Logistic Regression model training
- Decision Tree, Random Forest and XGBoost model comparison
- Model evaluation using Accuracy, Precision, Recall, F1 Score and ROC-AUC
- Fraudulent and legitimate transaction prediction
- Transaction summary and separate transaction tables
- Confusion Matrix visualization
- Graphical comparison of model performance
- Downloadable prediction results
